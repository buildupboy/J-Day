# 라이트 디자인 로컬 통합

기준 브랜치: feat/light-design (426da32), 기존 기준 develop (8f46983).

## 유지한 연결

- 새 홈/캘린더/일정/마이/제이 UI와 새 탭·오버레이 구조를 사용합니다.
- 제이는 기존 과제 확인 카드(cardMode=existing), 수정 후 저장 카드와 마감 시각을 유지합니다. 카드의 일정/캘린더 이동도 새 nav 인터페이스에 연결합니다.
- 10초 이상 대기 안내, 60초/120초 AI 제한과 개발 프록시 응답 대기 설정을 유지합니다.
- 마이 화면의 수면·휴식·선호·작업 스타일은 기존 PatternSettingsPage와 /api/user/settings 저장 API를 사용합니다. 새 디자인의 조회 전용 안내로 되돌리지 않습니다.
- useLiveSchedule은 fixedKind와 date를 모두 전달하므로 고정 일정 레이블과 개별 날짜의 휴지통 기능이 함께 동작합니다.
- 캘린더는 왼쪽 스와이프가 다음 주, 오른쪽이 이전 주입니다. 선택한 일정의 자세히에서 기존 삭제 기능을 사용할 수 있습니다.
- 홈의 가장 빠른 마감은 날짜뿐 아니라 실제 마감 시각으로 비교하여 이미 지난 마감을 제외합니다. 상세창은 새 DeadlineSheet로 연결됩니다.

## 다음 백엔드 병합 확인

- 새 NewEventPage는 디자인 브랜치 원본부터 저장 API가 미연결입니다. 날짜별 약속·반복 일정 저장 API를 다음 백엔드와 연결해야 합니다. 화면에서는 저장 미연결 안내를 표시합니다.
- FinishTaskPage는 기존 진행 보고 API를 호출합니다. 휴식/앞당김 등 선택 값에 따른 서로 다른 배치 정책을 추가하려면 다음 백엔드와 계약을 맞춰야 합니다.
- 기존 AI contextId/taskId/subtaskId/placementReason 및 사용자 설정 JSON 계약은 변경하지 않았습니다.
