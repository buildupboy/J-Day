# AI 예상시간 추천

POST /api/tasks/estimate 입력: {title, description, files:[{name,text}]}.
출력: {type,baseEstimatedMinutes,subtasks:[{title,estimatedMinutes}],rangeMinutes:[min,max],assumptions,source:"ai"}.

이 경로는 DB 조회/저장/개인 보정/스케줄러를 호출하지 않습니다. AI 요청 1회로 유형·소요시간·하위작업·가정을 함께 반환합니다. 스키마·정수 분·합계·범위를 서버가 검증합니다. 잘못된 응답을 고정 예시로 대체하지 않습니다. 개인 속도 보정은 기존 작업 등록에서만 한 번 적용합니다.

같은 입력은 5분간 최대 32개 캐시하며 병렬 중복 호출도 합칩니다. 다른 입력의 동시 추정은 최대 4개입니다. 실패는 캐시하지 않습니다. 모델은 기존 OPENAI_MODEL을 사용하고 전용 대기 제한 LLM_ESTIMATE_TIMEOUT_MS는 기본 25000ms입니다. 빠른 응답을 목표로 짧은 출력과 한 번의 요청을 사용하지만 실제 응답 속도는 모델·입력·서비스 상태에 따라 달라집니다.

브라우저는 텍스트 PDF와 UTF-8 TXT를 읽고 내용을 한 요청에 담습니다. PDF.js는 PDF를 선택했을 때만 로드합니다. PDF/TXT 최대 3개, 파일당 2MB, PDF 최대 20페이지, 파일별 텍스트 12000자, 설명+첨부 총 16000자입니다. 스캔/암호 PDF는 지원하지 않으며 오류를 보여 줍니다. 파일/본문은 사용자가 추천 버튼을 눌렀을 때 모델에 전달됩니다. PDF.js 사용법: https://mozilla.github.io/pdf.js/examples/

입력 변경 시 이전 추천을 지우고 응답을 무시/취소합니다. 추천 적용 시 분 단위 값을 시간/분 입력란에 나눠 넣고 하위작업과 유형도 전달합니다. 직접 시간을 고치면 기존 하위작업은 해제해 합계 불일치를 방지합니다. 추천과 적용만으로 저장/재배치하지 않습니다. 추가하고 배치하기의 기존 동작은 유지합니다.

가상 실제 AI 검증: 한 쪽 요약 50분(약4.7초), 신규 분석 15쪽 보고서 1680분(약8.1초). 같은 입력 재호출 1ms. 수치는 1회 측정 사례이며 보장값이 아닙니다. 브라우저에서 추천 요청·범위/가정 표시·입력란 적용을 확인했고 실제 과제 등록은 실행하지 않았습니다.
