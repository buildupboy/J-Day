# J-Day 기획

## 한 줄 소개

말로 맡기는 AI 일정 비서. "헤이 제이"라고 부르고 과제를 말하면, 제이가 작업량을 추정해 빈 시간에 넣어 준다.

## 타깃

1차: 대학생 — 시간표, 과제, 알바, 루틴이 섞여 있고 "언제 할지" 계획이 자주 무너지는 사람.

## 핵심 흐름

1. **등록**: 음성으로 과제·일정을 말한다 → LLM이 제목·마감·유형을 뽑고 하위작업과 기본 소요시간을 추정한다.
2. **보정**: 과거 수행 기록으로 유형별 개인 보정 계수를 곱한다 (예: 보고서는 늘 1.4배 걸림).
3. **배치**: 규칙 기반 스케줄러가 고정 일정(수업·알바·루틴) 사이 빈 시간에 작업 블록을 넣는다.
4. **보고·재배치**: 진행 상황을 말하면 진행률을 갱신하고, 미완료분이나 새 작업이 생기면 이후 일정을 다시 짠다.

## 역할 분리

| 담당 | 하는 일 |
|---|---|
| LLM | 발화 이해(의도·슬롯), 하위작업 분해, 기본 소요시간 추정, 응답 문장 |
| 스케줄러 (규칙 기반) | 빈 시간 계산, 블록 배치, 재배치 — 결과가 항상 설명 가능해야 함 |

## 시연 시나리오 (초안)

1. 오늘 타임라인 확인 — 수업·알바·운동 사이 빈칸이 보임
2. "헤이 제이, 다음 주 수요일까지 데이터베이스 보고서 있어" → 작업 등록 + 블록 배치
3. "ERD 반밖에 못 했어" → 진행률 갱신 + 남은 분량 재배치
4. 개인 보정 계수 덕분에 추정시간이 기본값보다 길게 잡히는 걸 보여 주기
